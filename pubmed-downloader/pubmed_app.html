Faster downloads

PubMed lets everyone make 3 requests a second. With a free NCBI API key it's 10, so big downloads finish up to about 3x faster.

  1. Go to account.ncbi.nlm.nih.gov/settings and sign in (you can use a Google account) or make a free account.
  2. Scroll to API Key Management and click Create an API Key.
  3. Copy the key and paste it below.
